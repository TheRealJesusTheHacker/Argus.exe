BEFORE YOU INSTALL
------------------
This installer will:

  * Put ARGUS.EXE in Program Files\Sentinel Safeguard\Argus.
  * Install and start the ArgusProtection Windows service, so
    real-time protection is on from boot, before you log in.
  * Register ARGUS.EXE with Windows Security Center as this
    computer's antivirus provider, so it appears by name in
    Windows Security.

Administrator rights are required, because a protection service
and Security Center registration are machine-wide settings.

YOUR DATA
---------
Argus keeps its data in one shared machine location:
C:\ProgramData\Argus. The protection service, the Argus app, and
the command line all use that same folder, so what one of them
sees is what all of them see.

The folder is split by trust, on purpose:

  * Settings and the signature database sit in the root, where
    standard Windows accounts can read but never change them.
  * The quarantine vault is locked down completely — only the
    Argus service and administrators can open it, so a piece of
    malware (or a curious hand) cannot reach what Argus caught.
    If the app cannot open the vault from your account, it shows
    the service's snapshot of it and asks the service to carry
    out restores and deletions for you.
  * A "shared" subfolder holds the status heartbeat, history,
    and your pending decisions — the pieces every account
    legitimately needs to see and answer.

If you ever uninstall: the program and service are removed, but
the vault and history are KEPT unless you check "remove all
data" in the uninstaller. Reinstalling picks up where you left
off.

FIRST RUN
---------
The first time you open ARGUS.EXE, a short welcome wizard helps
you pick the folders to watch and how Argus should respond when
it finds something — including a self-test that proves detection
works on this machine.
