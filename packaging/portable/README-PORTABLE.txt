ARGUS.EXE - Portable Edition
Sentinel Safeguard LLC - Security For Everyone

WHAT THIS IS
------------
The full Argus antivirus & malware detector in portable form.
It is the exact same Argus.exe as the regular edition — one file
that contains everything — run in portable mode. Unzip anywhere
(a USB stick works), double-click Argus-Portable.bat, and Argus
runs.

HOW PORTABLE MODE WORKS
-----------------------
Launch with Argus-Portable.bat, not Argus.exe directly. The
launcher points Argus at the "ArgusData" folder beside it, so
your settings, quarantine vault, and scan history all live in
that one folder and travel with it. Delete the folder and Argus
is gone without a trace.

Portable Argus never installs itself: it does not set up the
always-on protection service and does not register with Windows
Security. That is by design — portable mode is for carrying
Argus with you, not for settling it onto a machine. (On a PC
where Argus should live permanently, run Argus.exe on its own
and choose "Set up protection" instead.)

WHAT'S DIFFERENT FROM THE INSTALLED VERSION (honest list)
----------------------------------------------------------
- No always-on protection service: real-time protection watches
  while the Argus app is open. It does not start at boot.
- No Windows Security Center registration: Windows Security will
  still list your other antivirus (if any) as the provider.
- Quarantine, delete, allow, history, the Dev Toolkit, and all
  scanning work exactly as in the installed version.

FIRST RUN
---------
The first launch shows a short setup: pick the folders to watch,
choose what Argus should do when it finds a threat, and run the
built-in EICAR self-test to watch the whole detection pipeline
work end to end.

Argus never deletes anything silently. Permanent deletion always
waits for your decision.
